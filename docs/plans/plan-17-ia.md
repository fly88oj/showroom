# §17 控制台信息架构重设计（第一轮评审稿）

> 立场：现状是「按系统模块摆功能」（展项管理里塞发布+部署+镜像+上传四块，数据库/状态监控各自为政），
>  publisher 的心智是「我的 Demo 们 + 发布 + 排障」三件事。本稿按任务重组 IA，逐条消解问题清单 A–F。
> 约束：零后端改动——现有 `/_api/*` 端点与前端签名能力已足够，全部为 DOM/JS 层重排。

## 0. 问题清单 → 方案映射

| # | 问题 | 解法所在节 |
|---|------|-----------|
| A | 访问地址显示 `http://127.0.0.1/…` 内部地址 | §2.4 URL 策略 |
| B | 内存需求两处填写（发布表单 + 部署表单） | §3 单一参数入口 |
| C | 「未部署」语义不明 | §2.5 状态语义 |
| D | 载入项目清单 / 刷新镜像清单手动按钮 | §4 自动加载策略 |

| F | 平台公钥 PEM 常驻页首 | §2.1 顶栏 + 设置对话框 |

## 1. 用户旅程重定义（心智模型）

发布者打开控制台只想回答三个问题：**我的 Demo 在哪（URL）？怎么发新的/更新？出问题了看哪里？**
默认落地页必须零点击回答第一个问题；后两个各只需一次导航。

### J1 发布新 Demo（最短路径，点击 ≤4）
1. 打开控制台 → 本机钥匙自测通过直接进入（无登录页触点；无钥匙才见「账号+密码」一步登录）。
2. 落地「我的展项」：自动加载完成，见到已有展项与对外 URL（空账号见空态卡「+ 发布新 Demo」）。
3. 点「发布新 Demo」（顶栏主按钮，全局唯一常驻 CTA）→ 进入「发布」页：项目名已预填随机 8 位，内存/端口已填默认。
4. 填镜像标签 + 选 tar 文件 → 点「发布」→ 状态条 ①压缩 ②上传 ③发布。
5. 完成：大字**对外 URL** + 复制按钮；返回展项页，新行经事件流自动从「发布中」翻为「运行中」。
触点：登录(0–1) → 展项页(0) → 发布表单(1 页 3 字段) → 状态条(0) → URL(复制)。

### J2 更新 Demo（URL 不变）
1. 打开控制台 → 展项列表已在（自动加载）。
2. 目标行点「更新」→ 跳「发布」页并预填：项目名（锁定可改）+ 上次发布的内存/端口/标签（§3.2 conf 记忆）+ 镜像源定位到该项目最近 tag。
3. 选新 tar（或镜像库下拉换 tag）→「发布」→ 状态条「重建中」→ 行状态自动翻回「运行中」。
触点：展项行(1) → 发布页(改 1–2 字段) → 完成。

### J3 看状态 / 排障
1. 打开控制台 → 展项列表状态列零滚动可见；页面可见期间订阅事件流，状态自动刷新（无「立即刷新」依赖）。
2. 点行展开详情抽屉：日志流（实时跟随）/ 环境变量 / 数据入口（DB+Redis）/ 上一版本 tag。
3. 按状态给下一步：「已停止」→ 行内「启动」；「异常」→ 看日志 + 重新发布；「未创建」→ 引导去发布页。
触点：展项页(0) → 行展开(1)。

## 2. 页面结构方案（新 IA）

### 2.1 顶栏（唯一常驻 chrome，高度 ≤56px）
`Showroom 控制台 · [账号 mono] [角色徽标 发布者/管理员] ······ [+ 发布新 Demo] [设置] [退出]`
- **设置对话框**（收纳全部低频账户项，解决 F）：平台公钥 PEM（textarea，存 localStorage）、修改密码、忘记此设备、**对外访问域名**（§2.4 的 publicBase 覆写项）。
- PEM 不再出现在任何默认页面；仅在 ①设置对话框 ②上传 tar / 恢复 DB 缺 PEM 时的内联引导条（「需要平台公钥 → 去设置」，点击打开对话框并聚焦 PEM 字段）两处出现。

### 2.2 导航：五个任务标签（+条件性管理）
| 标签 | 承载任务 | 取代现状 |
|------|---------|---------|
| **我的展项**（默认） | 列表 + 行详情抽屉（日志/env/DB 入口）+ 状态自动刷新 | 展项列表 + 状态监控两页合一 |
| **发布** | 单一发布表单（新发/更新/选已有镜像，见 §3） | 「发布新版本」+「部署」两个 fieldset 合一 |
| **镜像库** | 镜像清单 + 删除 + 空间条 + 仅上传 + 断点续传 | 「镜像分片上传」fieldset + 部署区镜像表 |
| **数据** | 项目选择 → 表清单/预览/SQL/备份恢复 + Redis 浏览 | 数据库页 + 状态监控页 Redis 区 |
| **帮助** | 文档、CLI 对照、常见错误、专家路径钥匙登录折叠 | 帮助页（不变） |
| **管理**（whoami admin 才渲染） | 账号钥匙 + 平台状态 + **平台事件流**（docker events 原始流降为管理员工具）+ 主机编排 | 管理页 + 状态监控页事件区 |

层级规则（解决 E 的「菜单层级不清」）：全站只允许 **顶栏 → 标签页 → 卡片** 三级；卡片内不再嵌
fieldset；每卡片 = 标题 + 状态副题（「已加载 N 项 · HH:MM:SS」）+ 内容 + 卡片头右侧统一 ⟳ 图标。

### 2.3 「我的展项」页（默认落地）
- 列：**名称 · 状态（§2.5）· 对外 URL（§2.4，主列）· 镜像标签 · 更新时间 · 操作**。
- 行内操作固定顺序：`打开 · 更新 · 日志 · 启动/停止 · 更多▾（回滚/环境变量/数据/删除）`——高频外露、低频收菜单，行内按钮 ≤5。
- 行点击展开详情抽屉：实时日志流（原状态监控页能力，按项目订阅）、环境变量表、数据页深链（带 project 参数）、上一版本 tag + 回滚。
- 页面可见即订阅 `/_api/events`（sr- 前缀过滤，2 秒去抖刷新行状态）；`document.hidden` 或离开标签即退订（服务端收尸子进程）。「每 10 秒自动刷新」勾选框取消——事件驱动 + TTL 兜底已覆盖。

### 2.4 URL 策略（解决 A）
- **主链接永远是发布者视角的对外 URL**：`externalUrl(p) = publicBase + '/' + project + '/'`。
- `publicBase` 解析顺序（纯前端，无后端改动）：
  1. 设置项「对外访问域名」（localStorage `sr.publicBase`，如 `http://47.107.155.180:10100`）；
  2. 未设置时：`location.origin` 若为公网 host 则用之（判定：host ∉ {localhost, 127.*, ::1, 10.*, 172.16–31.*, 192.168.*}）；
  3. 仍无 → 用 `location.origin` 兜底（当前浏览器可达即正确），并在列表首行上方给一次性提示条「正在用内网地址展示 URL，可在设置中配置公网域名」。
- 服务端返回的 `p.url`（可能是 `http://127.0.0.1/…`）**永不作主链接**；仅放进 URL 单元格 tooltip「服务器内部地址：…」作次要信息。
- 生效范围：展项列表 URL 列、发布完成大字 URL、复制按钮、start/rollback 成功提示——全站 URL 一律走 `externalUrl()`。

### 2.5 状态语义重定义（解决 C）
| 后端 status | 显示文案 | 色 | tooltip |
|------------|---------|----|---------|
| running | 运行中 | 绿 | — |
| exited | 已停止 | 黄 | 容器已退出，可点「启动」恢复 |
| created | 已创建（未启动） | 黄 | 容器已创建但从未启动 |
| restarting | 重启中 | 黄 | 平台自愈中，稍候自动更新 |
| paused | 已暂停 | 黄 | — |
| dead | 异常 | 红 | 容器不可恢复：查看日志后重新发布 |
| missing | **未创建** | 灰 | **没有容器**（仅存在项目记录/镜像）；从发布页发布后自动创建 |
| （客户端瞬时） | 发布中… / 重建中… | 黄(动画) | publish/start/stop/rollback 请求在途时本地标记该行 |

「未部署」一词全站禁用；「已上传未发布」语义由镜像库页承载（镜像在库、项目未创建 = 镜像库有行 + 展项列表无行/未创建）。

### 2.6 视觉规范（解决 E）
- **间距刻度** 4/8/12/16/24/32：卡片内边距 16、卡片间距 16、表单字段行距 12、label 与控件 4、节间距 24。
- **字体**：页面标题 18/600；卡片标题 15/600；正文与控件 14；label/辅助 13；注释、时间、代码、URL 12（mono + tabular-nums）。全站不再出现 16px/20px 之外的标题字号（大字 URL 20/700 唯一例外）。
- **对齐**：表单一律 label 上控件下、grid 底对齐；表格文本列左对齐、时间/数字列右对齐；操作按钮统一行尾固定顺序。
- **色彩语义**：绿=可用、黄=过渡/停止、红=故障/破坏性、灰=不存在；破坏性按钮统一 `.danger` 且必须 confirm。

## 3. 消除重复（解决 B）

### 3.1 单一参数入口
「内存需求」「监听端口」「镜像标签」「项目名」全站**只在发布页表单出现一次**。删除现状 dep-form
整个表单及其 dep-mem/dep-cport 字段。发布表单结构：

```
项目名 [____][换一个]   镜像源 ( ● 本地 tar 文件 [选择…]  ○ 镜像库已有镜像 [下拉过滤…] )
镜像标签 [____]        内存需求 [256m▾]   监听端口 [8080]
[ 发布 ]  [ 仅上传（选了 tar 时可用） ]        ← 状态条 ①压缩 ②上传 ③发布 ④完成
```
- 选「本地 tar」→ 走压缩+分片上传+publish（现一键部署）；选「镜像库镜像」→ ①②标 skip，直接 publish（现第三入口）。三入口收敛为一个表单两种镜像源，语义即「新发/更新/旧版本单独部署」全部覆盖。
- 选镜像库镜像时项目名与标签从镜像串自动带出（保留现 onImagePick 逻辑），可改。

### 3.2 部署历史镜像：参数从上次 conf 带出
- 客户端 conf 记忆：每次 publish 成功写 `localStorage['sr.conf.'+project] = {tag, mem, cport, ts}`。
- 发布页项目名输入/选中命中已有记忆 → mem/cport/tag 自动回填，字段下方注「沿用上次发布参数（MM-DD），可修改」；无记忆 → 默认 256m/8080。
- 展项行「更新」→ 带 project 跳发布页，触发同一回填。
- 边界：记忆属本浏览器（换设备/清缓存回落默认值）；因 publish 请求参数完备，不影响正确性，非后端状态。

## 4. 自动加载策略（解决 D）

**原则：任何列表/下拉的数据在页面打开时已到位；「载入 XX 清单」类按钮全部删除**（含数据库页
「载入项目清单」、部署区「刷新镜像清单」）。卡片头 ⟳ 图标是唯一的兜底手动重取，非必经步骤。

| 数据源 | 端点 | 加载时机 | 并发 | 缓存 / 失效 | 失败重试 |
|--------|------|---------|------|------------|---------|
| projects | GET /_api/projects | 登录后立即；切到展项/发布/数据页且 TTL 过期 | 登录四路 `Promise.allSettled` 并发 | 内存 + fetchedAt，TTL 30s；publish/start/stop/rm/rollback 成功后与事件流去抖(2s)后强制重取 | 卡片内联错误 + 3s 后自动重试 1 次 + ⟳ 手动 |
| images | GET /_api/images | 登录后立即；切到发布/镜像库页且 TTL 过期；whoami 判定 admin 后重取（刷新管理员视图标注） | 同上 | TTL 300s；仅上传/import-end/image-rm 成功后强制重取 | 同上 |
| space | GET /_api/space | 登录后立即；切到镜像库/发布页；import-end/image-rm 后 | 同上 | TTL 60s | 静默降级「空间信息不可用」，30s 后再试 |
| whoami | GET /_api/whoami | 登录后立即（决定管理标签与 admin 标注） | 同上 | 会话级缓存 | 顶栏角色徽标显「?」，60s 周期重试至成功 |
| redis-dbs | GET /_api/redis-dbs | 惰性：数据页 Redis 区首次展开 | 单路 | 会话级；发布/删除项目后失效 | 内联 + 重试按钮 |
| events 流 | GET /_api/events | 展项页可见时订阅；hidden/离开退订 | 流式 | — | 断开 5s 自动重连（保留现状） |
| admin/users · status · host | 各 admin 端点 | 切到管理页 | 三路并发 | 切页重取 | 内联 + ⟳ |

数据库页项目下拉、发布页项目名 datalist 直接消费已加载的 `state.projects`——不再有独立加载动作。

## 5. 验收清单（用户视角可测试断言）

1. 钥匙自动登录后 **3 秒内、零点击**：展项列表完整可见，每行含中文状态、可点击的对外 URL、更新时间；无任何「未加载」占位。
2. 全站 URL 主链接不出现 `127.0.0.1`/内网 host（配置了公网域名时）；服务器内部地址仅存在于 tooltip。复制按钮与发布完成大字 URL 复制出的均为对外 URL。
3. DOM 中检索「载入项目清单」「刷新镜像清单」文本为零；数据库页项目下拉、发布页镜像下拉零点击即含全量数据。
4. 「内存需求」「监听端口」label 全站各恰好出现 1 次（发布表单）；旧 dep-form 不存在。
5. 状态文案集合 = {运行中, 已停止, 已创建（未启动）, 重启中, 已暂停, 异常, 未创建, 发布中…, 重建中…}；「未部署」零出现；悬停「未创建」tooltip 明示「没有容器」。
6. 默认任何页面不见平台公钥 PEM；未配置 PEM 时选 tar 发布 → 内联引导「去设置」→ 打开对话框且焦点在 PEM 字段。
7. 更新流：某项目上次以 mem=512m/port=9000 发布成功后，点该行「更新」→ 发布页项目名/内存/端口预填一致并注「沿用上次发布参数」。
8. 断网打开页面：各卡片独立显示内联「加载失败 + 重试」，3 秒自动重试一次；恢复网络后无需刷新页面即自动补齐。
9. 顶栏仅一行（≤56px）：账号、角色徽标、发布 CTA、设置、退出；设置对话框含 PEM/改密/忘记设备/公网域名四项。
10. J1 全程（自动登录起，除文件选择与表单填写外）鼠标点击 ≤4 次拿到 URL；J3 从打开页面到看见某展项实时日志 ≤2 次点击。
11. 展项页停留期间在别处 stop 某容器：≤5 秒内该行状态自动变「已停止」，无手动刷新（事件流 + 去抖生效）。
12. 视觉抽查：任意两卡片标题字号/内边距一致；间距值全部落在 4/8/12/16/24/32 刻度；表格时间列右对齐且等宽数字。

## 6. 实施提示（不改后端、不改 API 契约）

- 改动集中在 `showroom-web/dist/index.html`：模板重排（tabs 五枚）、`enterApp()` 四路并发、
  `externalUrl()` 助手、`STATUS_CN` 换表、dep-form 删除并入 pub-form（镜像源 radio）、
  `sr.conf.*` 读写、PEM 迁入设置 dialog、事件流订阅移到展项页可见性钩子。
- 现有 wasm 垫片、签名、上传/下载/续传、OPAQUE 登录逻辑全部原样复用，仅搬 DOM 与调用时机。
